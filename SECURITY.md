# Security policy

## Supported versions

| Version | Supported |
|---|---|
| The newest 0.1 release | Yes |
| Any older release | No |

## Reporting a vulnerability

Report it privately, through GitHub's private vulnerability reporting: on the repository's Security tab, choose Report a
vulnerability, or open [a new advisory](https://github.com/ApGa/platoon-harness/security/advisories/new). Do not report
it in a public issue, pull request or discussion.

Say what an attacker can do, what `platoon-harness --version` prints, each harness involved and its version, your OS,
and the steps that show it. The report stays between you and the maintainers until they publish an advisory.

[docs/security.md](docs/security.md) says what platoon-harness protects and what it does not.
